# Vektor Protocol (vektor-web3-template)

Reusable, anti-slop Web3 landing page and operational dashboard template built iteratively across 8 structured phases using a strict multi-skill authority hierarchy.

## Skill Authority Matrix

- **Visual System & Final Gate:** `design-taste-frontend` (wins on layout, density, and visual conflicts)
- **Structure & Copy:** `landing-page`
- **Dashboard & Product UI:** `impeccable` + `shadcn` + `d3-visualization`
- **Color & Typography:** `better-colors` (OKLCH) + `typeset`
- **Hero & WebGL:** `webgl-landing-steering` (Lane B), `globe-particles`, `globe-gl`, `webgl-components`
- **Scroll & Micro-Interactions:** `cinematic-scroll-storytelling` (wins on scroll timing, max 1 pinned section), `emil-design-eng`, `animation-performance`, `accessible-animation`
- **Shipping Gates:** `web-design-guidelines` + `critique`
